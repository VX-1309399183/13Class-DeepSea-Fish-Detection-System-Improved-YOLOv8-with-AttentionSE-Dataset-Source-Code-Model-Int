## ✨ 核心亮点
- **三模型内置可切换**：同一数据集下可直接切换 YOLO11s、YOLOv8s、YOLOv8s-attention-SE，按需权衡检测精度与推理速度。
- **注意力增强模型**：YOLOv8s-attention-SE 引入 SE 注意力机制，在复杂背景、目标遮挡场景下识别更稳定。
- **一体化工程架构**：检测推理、结果统计、历史入库、图表分析、报告导出闭环完成，并非单一推理脚本。
- **中英类别映射**：模型英文类别自动转换为中文展示，检测结果可直接用于演示汇报与业务沟通。
- **双入口版本**：提供无登录版与登录版两套界面，既能快速演示，也方便后续做权限化扩展。
